## ADD

**格式**: `ADD rd, rs1, rs2`

**编码**: `0000000 rs2[4:0] rs1[4:0] 000 rd[4:0] 0110011`

**描述**: 将两个寄存器的值相加

**操作步骤**:
- 1. 读取寄存器rs1和rs2的值
- 2. 执行32位有符号加法运算
- 3. 将结果写入寄存器rd
- 4. 溢出时结果被截断

**用法**:
- rd = rs1 + rs2
- 基本算术运算
- 地址计算

**示例**:
```asm
ADD x1, x2, x3  # x1 = x2 + x3
```

**异常**: 无异常产生

**应用场景**: 基本算术、地址计算、数组索引

**注意**: 最基本的算术运算指令

## SUB

**格式**: `SUB rd, rs1, rs2`

**编码**: `0100000 rs2[4:0] rs1[4:0] 000 rd[4:0] 0110011`

**描述**: 从第一个寄存器值中减去第二个寄存器值

**操作步骤**:
- 1. 读取寄存器rs1和rs2的值
- 2. 执行32位减法：rs1 - rs2
- 3. 将结果写入寄存器rd

**用法**:
- rd = rs1 - rs2
- 减法运算
- 指针运算

**示例**:
```asm
SUB x1, x2, x3  # x1 = x2 - x3
```

**异常**: 无异常产生

**应用场景**: 基本算术、指针运算、比较运算

**注意**: 减法运算，注意操作数顺序

## ADDI

**格式**: `ADDI rd, rs1, imm`

**编码**: `imm[11:0] rs1[4:0] 000 rd[4:0] 0010011`

**描述**: 寄存器值与12位立即数相加

**操作步骤**:
- 1. 读取寄存器rs1的值
- 2. 将12位立即数符号扩展到32位
- 3. 执行加法运算：rs1 + imm
- 4. 将结果写入寄存器rd

**用法**:
- rd = rs1 + imm
- 立即数范围：-2048到2047

**示例**:
```asm
ADDI sp, sp, -16  # 栈指针调整
ADDI t0, zero, 42  # 加载常数42
```

**异常**: 无异常产生

**应用场景**: 加载常数、栈指针调整、地址偏移

**注意**: 最常用指令之一，可加载小常数

## AND

**编码**: `0000000 rs2[4:0] rs1[4:0] 111 rd[4:0] 0110011`

**操作步骤**:
- 1. 读取寄存器rs1和rs2的值
- 2. 对每一位执行逻辑与运算
- 3. 将结果写入寄存器rd

**用法**:
- rd = rs1 & rs2
- 位掩码操作
- 清除特定位

**示例**:
```asm
AND x1, x2, x3  # 按位与运算
```

**异常**: 无异常产生

**应用场景**: 位掩码、清除位、位运算优化

**注意**: 基本逻辑运算

## SLL

**格式**: `SLL rd, rs1, rs2`

**编码**: `0000000 rs2[4:0] rs1[4:0] 001 rd[4:0] 0110011`

**描述**: 逻辑左移

**操作步骤**:
- 1. 读取寄存器rs1的值
- 2. 读取rs2的低5位作为移位数
- 3. 执行逻辑左移
- 4. 将结果写入rd

**用法**:
- rd = rs1 << rs2[4:0]
- 移位数0-31
- 乘以2的幂

**示例**:
```asm
SLL x1, x2, x3  # x1 = x2 << x3
```

**异常**: 无异常产生

**应用场景**: 乘以2的幂、位域操作、地址计算

**注意**: 左移一位等于乘以2

## SLT

**格式**: `SLT rd, rs1, rs2`

**编码**: `0000000 rs2[4:0] rs1[4:0] 010 rd[4:0] 0110011`

**描述**: 有符号比较小于

**操作步骤**:
- 1. 读取寄存器rs1和rs2的值
- 2. 执行有符号比较：rs1 < rs2
- 3. 如果rs1 < rs2则rd=1，否则rd=0

**用法**:
- rd = (rs1 < rs2) ? 1 : 0
- 有符号比较

**示例**:
```asm
SLT x1, x2, x3  # x1 = (x2 < x3)
```

**异常**: 无异常产生

**应用场景**: 条件判断、分支条件、最值比较

**注意**: 有符号数比较

## LW

**格式**: `LW rd, offset(rs1)`

**编码**: `offset[11:0] rs1[4:0] 010 rd[4:0] 0000011`

**描述**: 加载32位字

**操作步骤**:
- 1. 计算地址：rs1 + offset
- 2. 从内存读取32位数据
- 3. 写入寄存器rd
- 4. 地址必须4字节对齐

**用法**:
- 加载32位数据
- 地址需要4字节对齐

**示例**:
```asm
LW x1, 0(sp)  # 从栈加载
LW x2, 100(x3)  # 偏移加载
```

**异常**: 地址对齐异常，访问故障

**应用场景**: 变量访问、数组元素、结构体字段

**注意**: 最常用的加载指令
